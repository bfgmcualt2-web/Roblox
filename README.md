# Kanto Remix

A browser-based, FireRed-inspired randomizer interface. It generates a reproducible run plan from a seed and lets players choose which parts of a run to shuffle.

## Run locally

Open `index.html` in a modern browser, or serve the directory with:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

This project does not include or distribute any game ROMs or game assets.
